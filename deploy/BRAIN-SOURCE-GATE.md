# AI research source gate

`TASHILRADAR_DIRECT_RESEARCH=true` enables direct public-page retrieval for goods/mobile topics. This separate server adapter uses fixed reviewed DigiPay goods-credit and BNPL pages, never a user/model URL. Requests carry no credentials or conversation, reject redirects, time out after 10 seconds and stop at 1 MB per page. Only text excerpts enter AI context. It bypasses paid search when usable evidence is retrieved. This is public research, not a partner API or approval. Other topics retain filtered search/general guidance. Search failure no longer prevents a general answer.

Server-only setting: `TASHILRADAR_RESEARCH_DOMAINS` is a comma-separated registry of reviewed public source hostnames (no scheme or path). Do not populate it from user input. Review source ownership, relevance, publication dates and conditions before enabling domains. Subdomains are included. An empty registry skips web research; general conversation remains available with an explicit no-verified-source instruction.

The search receives only the fixed generic service topic, never private conversation or budgets. Search is required when enabled and requests the consulted-source list. A research summary enters the private answer only when a completed search exists, citations and consulted sources are present, and every URL is HTTPS and within the registry. Mixed-source summaries are discarded entirely. Retrieval timestamps do not establish publication dates, offer validity, eligibility, partnership or availability. This is a provenance gate, not a guarantee of factual correctness or complete prompt-injection protection.

Verification: `npx bun test src/lib/brain.server.test.ts src/lib/brain-policy.test.ts`. Tests use synthetic responses, not paid live inquiries. No production configuration or release was changed by this patch. Before activation, configure a reviewed registry and verify a real canary response, source relevance and explicit uncertainty. Keep the prior deployed image for rollback; setting `TASHILRADAR_BRAIN_ENABLED=false` disables AI without removing the existing deterministic flow.
