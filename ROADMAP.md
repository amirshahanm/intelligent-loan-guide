# Public Roadmap

This roadmap tracks open-source work rather than private commercial plans.

## Near term

- strengthen deterministic test coverage for readiness and recommendation boundaries
- document mocked-provider interfaces
- add fixtures for Persian conversational intake
- improve RTL and accessibility regression coverage
- document provenance and explainability requirements
- tighten privacy-safe analytics boundaries
- expand reduced-motion QA

## Later

- pluggable provider adapters
- auditable decision-envelope examples
- reusable policy checks for unsupported financial claims
- optional Codex-assisted maintainer automation
- release automation and changelog generation

Roadmap items are directional and may change based on issues, contributor feedback, and security review.
